# omsiStartSteam-BBS

# Informations
Ce fichier vide à glisser dans le dossier OMSI 2/Busbetrieb-Simulator désactive le démarrage automatique d'OMSI engagé par Busbetrieb Simulator une fois votre service choisi dans le menu, que ce soit en joueur solo ou en mode multijoueur. **Lorsque ce fichier est présetn dans votre Busbetrieb-Simulator, il faudra donc lancer manuellement OMSI via le dossier où il est installé, par le biais du Omsi.exe.**
Astuce vue sur un forum de simulation allemand.

Via ce système de lancement manuel, cela permettra à OMSI de se lancer avec les paramètres activés dans certaines conditions:
- Démarrage en mode de compatibilité Windows 7
- Désactivation des optimisations en plein écran (lorsque vous utilisez Vulkan au lieu de Direct X)
- Démarrage en tant qu'Administrateur
